## Estructura de carpetas

- `EJERCICIO 1 Ficha de un viaje/`: Practica 1 con JavaScript para mostrar los datos del viaje.
- `EJERCICIO 2. PANEL DE CONSUMO.../`: Practica 2 con la calculadora de costes y combustible.
- `EJERCICIO 3 Validador de datos.../`: Practica 3 con la validacion del formulario de registro.
- `albor-logistics/`: Practica 4 con la web completa (HTML, CSS y JS).

## Cómo ejecutarlo

Para ver cualquiera de los ejercicios solo hay que abrir el archivo `index.html` de cada carpeta en el navegador (Chrome, Firefox, Edge, etc.). No hace falta instalar nada ni usar servidor local.

## Decisiones de desarrollo

- He separado todo el codigo JavaScript en archivos `.js` externos dentro de carpetas `js/` para no mezclarlo con el HTML.
- Se han hecho las validaciones de los datos en el lado del cliente para avisar al usuario si introduce campos vacios o datos incorrectos.
