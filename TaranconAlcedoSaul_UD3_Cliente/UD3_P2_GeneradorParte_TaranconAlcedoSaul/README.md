# UD3 – PRÁCTICA 2: Generador de partes de viaje

## Descripción
Aplicación web para ALBOR LOGISTICS que recopila datos mediante un formulario y genera de forma dinámica el parte de viaje en pantalla y en una nueva ventana emergente utilizando JavaScript.

## Archivos
- `generador-parte.html`: Formulario de entrada y zona de renderizado del parte.
- `js/parte.js`: Captura de datos, validación, inserción en el DOM y apertura de pop-up con la fecha del sistema (`Date`).
