# UD3 – PRÁCTICA 2: Generador de partes de viaje

## Descripción
Formulario que recopila datos de transporte y genera un documento visual de parte de viaje dinámicamente en el DOM y en una ventana emergente mediante `Date()` y `window.open()`.

## Estructura
- `generador-parte.html`: Formulario principal.
- `js/parte.js`: Lógica de validación, renderizado y generación de documento.
