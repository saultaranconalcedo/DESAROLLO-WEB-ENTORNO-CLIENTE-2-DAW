# UD3 – PRÁCTICA 3: Preferencias del operador mediante cookies

## Cookies utilizadas
1. `op_nombre`: Nombre del operador guardado para el saludo de bienvenida.
2. `op_idioma`: Guarda la preferencia de idioma (`Español` o `Inglés`).
3. `op_numViajes`: Número de registros a mostrar (`10`, `20` o `50`).
4. `op_ultimoPanel`: Último módulo activo (`Viajes`, `Camiones`, `Conductores` o `Clientes`).

## Operaciones
- **Crear / Modificar**: Expiración futura calculada a 30 días.
- **Eliminar**: Expiración forzada mediante fecha pasada (`01-Jan-1970`).
