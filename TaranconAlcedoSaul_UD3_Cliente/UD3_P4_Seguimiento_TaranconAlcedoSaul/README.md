# UD3 – PRÁCTICA 4: Panel de seguimiento de ALBOR LOGISTICS

## Descripción
Panel que integra módulos dentro de un `iframe` interactuando con `contentWindow` para la recarga del documento interno y la apertura de subpáginas en ventanas independientes.

## Estructura
- `index.html`: Panel contenedor.
- `viajes.html`, `camiones.html`, `conductores.html`: Vistas.
- `js/app.js`: Script principal de interacción.
