# UD3 – PRÁCTICA 1: Centro de operaciones de ALBOR LOGISTICS

## Descripción
Panel de control para abrir ventanas, navegar por el historial y modificar URLs externas usando los objetos `window`, `location`, `navigator` y `document`.

## Estructura
- `centro-operaciones.html`: Panel principal.
- `seguimiento.html`: Vista de seguimiento en ventana emergente.
- `js/app.js`: Lógica y manipulación de ventanas.
