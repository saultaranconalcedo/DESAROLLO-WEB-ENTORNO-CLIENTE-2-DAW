# UD3 – PRÁCTICA 1: Centro de operaciones de ALBOR LOGISTICS

## Descripción
Panel de control sencillo para gestionar ventanas y recursos de trabajo utilizando los objetos propios de JavaScript (`window`, `location`, `navigator` y `document`).

## Archivos
- `centro-operaciones.html`: Página principal con el panel de botones e información.
- `seguimiento.html`: Pop-up o ventana secundaria de seguimiento.
- `js/app.js`: Lógica y control de eventos.
